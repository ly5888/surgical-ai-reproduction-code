# Surgical AI Reproduction Code

This repository contains reproduction code for four surgical AI studies.

## Projects

| Project | Task |
|---|---|
| 008 | MUTA-based surgical image segmentation |
| 017 | Sum-of-Checks reasoning for surgical safety |
| 061 | VitalDB intraoperative hypotension prediction |
| 080 | ESWL treatment outcome prediction |

## Notes

- Each project has its own README with detailed instructions.
- Patient data, model weights, API keys, and `.env` files are not included.
- Some projects are approximate or partial reproductions because the original data or implementation was not publicly available.
